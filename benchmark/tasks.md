# Task shape

Each task: one paragraph of intent, the files it touches, and an acceptance check that a script can run (tests pass, a command prints X). Examples of the mix to include:

- add a field end to end (model, API, UI, tests);
- fix a bug with a known failing test;
- rename a concept across the repo;
- add input validation with tests;
- extract a module and update callers;
- add a CLI flag with docs;
- migrate a config format;
- add pagination to a list endpoint;
- write tests for an untested module;
- one deliberately small task (one file), to see where duo stops paying off.
